# CCCC - Clean ・ Compact ・ Care ・ Color
**「掃除して整頓しケアをして色を添える」**  
「これは何のフォルダ？」「消しても大丈夫？」が一目でわかり、誰でも安心してPCを片付けられるデスクトップアプリケーションです。

---

## 🌟 主な特徴・機能（全6タブ＋ドラッグ＆ドロップ対応）

### 🎨 目に優しく見やすいパステルカラーテーマ（黒文字ベース）
画面右上の「**🎨 背景カラー**」から、いつでもお好みの淡いカラーに切り替えられます（設定は自動保存されます）：
* **💧 パステルブルー（標準）**: 爽やかで清潔感のある淡い水色＋黒文字
* **🌼 パステルイエロー**: 温かみのあるクリームイエロー＋黒文字
* **🌸 パステルピンク**: 優しく明るいさくらピンク＋黒文字
* **🌿 パステルミント**: 目に優しい淡いミントグリーン＋黒文字
* **🌙 ダークモード**: 夜間作業向けの暗色テーマ

---

### 1. 🏠 ホーム診断（ダッシュボード）
* **ドラッグ＆ドロップ即診断**: エクスプローラーから「これ何だろう？」と思うフォルダやファイルを画面にドロップするだけで、正体と安全性を即座に診断します。
* **Cドライブ空き容量・削減可能キャッシュのひと目確認**
* **目的別クイックスタートボタン**

### 2. 📁 フォルダ整理・中身診断タブ
* **🕵️‍♂️ アンインストール済みアプリの残骸（孤児フォルダ）検出**: Windowsレジストリのインストール情報と照合し、`AppData` 内に残された使われていない古いフォルダを検出します。
* **📖 有名アプリ・謎フォルダ正体辞書**: `Discord`, `VSCode`, `Steam`, `Adobe`, `node_modules`, `__pycache__`, `SquirrelTemp` などの役割を日本語でわかりやすく解説。
* **📊 カラフルなドーナツグラフ（円グラフ）**: フォルダ内の画像・動画・書類などの割合を視覚的に表示。
* **🛡️ 保護リスト（ホワイトリスト）ボタン**: 大切なフォルダやファイルをワンクリックで保護し、誤削除・移動を完全にブロック。

### 3. 👯 重複ファイル検出タブ
* ファイル名が違っても中身（SHA-256ハッシュ）が100%同じ重複ファイルを高速検出。
* **「原本（1つ目）を残して重複コピーだけ自動チェック」**ボタンで、無駄なコピーだけを安全にゴミ箱へ送れます。

### 4. 🧹 キャッシュ・一時ファイル削除タブ
* Windows一時ファイル（Temp）、Chrome/Edgeキャッシュ、サムネイルキャッシュ、クラッシュダンプを一括・個別クリア。

### 5. ⚙️ ドライブ最適化 & デフラグタブ
* ドライブ使用率メーター、断片化クイック分析、Windows標準の最適化ツールのワンクリック起動。

### 6. 📜 操作履歴タイムライン & 🛡️ 保護リスト管理タブ
* いつ・どのファイルをどこへ仕分け移動したかを記録し、**後からいつでも個別に元の場所へ復元**可能。
* 保護登録したフォルダ・ファイルの一覧管理と解除。

---

## 🚀 起動と配布ビルド方法

* **通常起動**: デスクトップの **「CCCC」** ショートカット、またはフォルダ内の `run.bat` をダブルクリック
* **単体 `.exe` 化（配布用ビルド）**: `build_exe.bat` をダブルクリックすると、`dist\CCCC\CCCC.exe` にPython不要の実行ファイル一式が生成されます。
